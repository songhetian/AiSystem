### 1.2 失败原因分析

所有测试失败的根本原因是**测试环境配置问题**,而非功能实现问题:

**问题**: `Error: No QueryClient set, use QueryClientProvider to set one`

**原因**:
- 测试文件直接渲染组件,没有使用 `QueryClientProvider` 包装
- 组件使用 `@tanstack/react-query` 的 `useQuery` hook,需要 QueryClient 上下文
- 测试设置文件 (`frontend/src/test/setup.ts`) 中缺少 QueryClientProvider 配置

**影响**:
- 这是测试基础设施问题,不影响实际应用功能
- 在实际应用中,App.tsx 已正确配置 QueryClientProvider
- 功能代码本身是正确的
