# Mock API Server - 快速开始

## 🚀 一键启动（推荐）

```bash
# 在项目根目录执行
npm run docker:up
```

**就这么简单！** Mock 服务会自动随项目一起启动。

## 📊 验证服务

```bash
# 1. 查看服务状态
npm run docker:ps

# 2. 查看 Mock 服务日志
npm run docker:logs:mock

# 3. 测试健康检查
curl http://localhost:3888/health
```

## 📡 API 地址

- **服务地址**：`http://localhost:3888`
- **API 文档**：`http://localhost:3888/`
- **健康检查**：`http://localhost:3888/health`

### 京东接口

```
GET /api/jd/orders          # 订单列表
GET /api/jd/order/:order_sn # 订单详情
GET /api/jd/chats           # 客服对话列表
```

### 拼多多接口

```
POST /api/pdd/orders/search # 订单列表
POST /api/pdd/order/detail  # 订单详情
POST /api/pdd/chats/list    # 客服对话列表
```

### 淘宝接口

```
GET /api/taobao/trades/sold/get      # 订单列表
GET /api/taobao/trade/fullinfo/get   # 订单详情
GET /api/taobao/im/messages/get      # 客服对话列表
```

## 🔑 签名算法

```
sign = MD5(app_key + timestamp + nonce + app_secret)
```

### 必需参数

- `app_key` - 应用Key
- `timestamp` - 时间戳（秒）
- `nonce` - 随机字符串
- `sign` - MD5签名

### 签名有效期

5 分钟

## 🎯 常用命令

```bash
# 启动所有服务（包含 Mock）
npm run docker:up

# 查看 Mock 服务日志
npm run docker:logs:mock

# 重启所有服务
npm run docker:restart

# 停止所有服务
npm run docker:down

# 重新生成测试数据
cd dev-tools && npm run generate
```

## ⚠️ 注意事项

1. **开发环境自动启动**：`NODE_ENV=development` 时，Mock 服务会自动启动
2. **生产环境不启动**：`NODE_ENV=production` 时，Mock 服务不会启动
3. **端口占用**：确保 3888 端口未被占用
4. **签名验证**：所有接口都需要签名验证
