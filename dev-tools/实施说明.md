# Mock API Server 实施说明

## ✅ 已完成

### 1. 创建新的 Mock Server (`mock-server-new.ts`)

**核心特性**：

- ✅ **独立的平台接口地址**
  - 京东：`/api/jd/*`
  - 拼多多：`/api/pdd/*`
  - 淘宝：`/api/taobao/*`

- ✅ **独立的平台凭证**

  ```typescript
  jd: {
    app_key: 'jd_leixin_2026',
    app_secret: 'jd_secret_8899'
  },
  pdd: {
    app_key: 'pdd_leixin_2026',
    app_secret: 'pdd_secret_7788'
  },
  taobao: {
    app_key: 'tb_leixin_2026',
    app_secret: 'tb_secret_6677'
  }
  ```

- ✅ **签名验证机制**
  - MD5(app_key + timestamp + nonce + app_secret)
  - 5分钟有效期
  - 防重放攻击

- ✅ **分页支持**
  - 京东：`page`, `page_size`
  - 拼多多：`page`, `page_size`
  - 淘宝：`page_no`, `page_size`

- ✅ **真实的接口格式**
  - 京东：GET 请求，标准 JSON 响应
  - 拼多多：POST 请求，`error_code` + `result` 格式
  - 淘宝：GET 请求，`xxx_response` 嵌套格式

## 📝 接口调用示例

### 京东订单列表

```bash
# 1. 生成签名
app_key="jd_leixin_2026"
app_secret="jd_secret_8899"
timestamp=$(date +%s)
nonce=$(openssl rand -hex 4)
sign=$(echo -n "${app_key}${timestamp}${nonce}${app_secret}" | md5sum | cut -d' ' -f1)

# 2. 调用接口
curl "http://localhost:3888/api/jd/orders?app_key=${app_key}&timestamp=${timestamp}&nonce=${nonce}&sign=${sign}&page=1&page_size=20"
```
