# Mock API Server 使用说明

## 🎯 功能概述

Mock API Server 模拟京东、拼多多、淘宝三大电商平台的真实接口，用于开发环境测试。

### 核心特性

- ✅ **独立的平台接口**：每个平台有独立的 API 路径
- ✅ **真实的签名验证**：MD5 签名算法，5分钟有效期
- ✅ **独立的平台凭证**：每个平台有独立的 app_key 和 app_secret
- ✅ **分页支持**：支持分页查询
- ✅ **真实数据**：120+ 条订单、120+ 组对话
- ✅ **JSON 文件存储**：无需数据库，使用 JSON 文件

## 📡 API 接口

### 京东接口

#### 1. 订单列表

```
GET /api/jd/orders
```

**请求参数**：

- `app_key` - 应用Key（必需）
- `timestamp` - 时间戳（必需）
- `nonce` - 随机字符串（必需）
- `sign` - 签名（必需）
- `page` - 页码（可选，默认1）
- `page_size` - 每页数量（可选，默认20）
- `order_state` - 订单状态（可选）

**响应示例**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 120,
    "page": 1,
    "page_size": 20,
    "total_page": 6,
    "order_list": [...]
  }
}
```

#### 2. 订单详情

```
GET /api/jd/order/:order_sn
```

#### 3. 客服对话列表

```
GET /api/jd/chats
```

## 🔑 签名算法

### 算法说明

```
sign = MD5(app_key + timestamp + nonce + app_secret)
```

### Node.js 示例

```javascript
const crypto = require("crypto");

const app_key = "jd_leixin_2026";
const app_secret = "jd_secret_8899";
const timestamp = Math.floor(Date.now() / 1000).toString();
const nonce = Math.random().toString(36).substring(2, 10);

const sign = crypto
  .createHash("md5")
  .update(`${app_key}${timestamp}${nonce}${app_secret}`)
  .digest("hex");

console.log("签名参数：");
console.log(`app_key=${app_key}`);
console.log(`timestamp=${timestamp}`);
console.log(`nonce=${nonce}`);
console.log(`sign=${sign}`);
```

### Bash 示例

```bash
#!/bin/bash

app_key="jd_leixin_2026"
app_secret="jd_secret_8899"
timestamp=$(date +%s)
nonce=$(openssl rand -hex 4)
sign=$(echo -n "${app_key}${timestamp}${nonce}${app_secret}" | md5sum | cut -d' ' -f1)

echo "签名参数："
echo "app_key=${app_key}"
echo "timestamp=${timestamp}"
echo "nonce=${nonce}"
echo "sign=${sign}"

# 调用接口
curl "http://localhost:3888/api/jd/orders?app_key=${app_key}&timestamp=${timestamp}&nonce=${nonce}&sign=${sign}&page=1&page_size=10"
```

## ⚠️ 注意事项

1. **仅用于开发环境**：Mock 服务仅用于开发测试，不要在生产环境使用
2. **签名有效期**：签名有效期为 5 分钟，过期需要重新生成
3. **数据临时性**：数据存储在 JSON 文件中，重新生成会覆盖
4. **端口占用**：确保 3888 端口未被占用
5. **Docker Profile**：Mock 服务使用 `dev` profile，需要显式启动

## 🐛 故障排查

### 问题1：签名验证失败

**原因**：签名计算错误或时间戳过期

**解决**：

1. 检查 app_key 和 app_secret 是否正确
2. 确认签名算法：MD5(app_key + timestamp + nonce + app_secret)
3. 检查时间戳是否在 5 分钟内

### 问题2：数据文件不存在

**原因**：未生成测试数据

**解决**：

```bash
cd dev-tools
npm run generate
```

### 问题3：端口被占用

**原因**：3888 端口已被其他程序占用

**解决**：

```bash
# 查看端口占用
lsof -i :3888

# 修改端口
# 在 .env 文件中设置
MOCK_SERVICE_PORT=3889
```
