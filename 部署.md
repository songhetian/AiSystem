## 部署方式选择

### 🏢 传统部署（推荐生产环境）

**适用场景**：

- 服务器已有 MySQL、Redis、Nginx 等服务
- 需要与现有系统集成
- 对性能要求较高
- 运维团队熟悉传统部署方式

### 🐳 Docker 部署

**适用场景**：

- 快速部署和测试
- 开发环境
- 容器化运维环境

### 🔄 混合部署

**适用场景**：

- 数据库使用服务器自带服务
- 应用使用 Docker 容器

## 传统部署（推荐生产环境）

### 环境要求

#### 服务器配置

- **CPU**: 4 核以上
- **内存**: 8GB 以上
- **存储**: 100GB SSD 以上
- **操作系统**: Ubuntu 20.04+ / CentOS 8+ / RHEL 8+

#### 软件依赖

- **Node.js**: >= 18.0.0
- **npm**: >= 9.0.0
- **MySQL**: >= 8.0
- **Redis**: >= 6.0
- **Nginx**: >= 1.18
- **PM2**: 进程管理器

### 1. 安装基础软件

#### Ubuntu/Debian 系统

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Node.js 18
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装 MySQL 8.0
sudo apt install mysql-server mysql-client -y

# 安装 Redis
sudo apt install redis-server -y

# 安装 Nginx
sudo apt install nginx -y

# 安装 PM2
sudo npm install -g pm2

# 验证安装
node --version
mysql --version
redis-cli --version
nginx -v
pm2 --version
```

#### CentOS/RHEL 系统

```bash
# 更新系统
sudo yum update -y

# 安装 Node.js 18
curl -fsSL https://rpm.nodesource.com/setup_18.x | sudo bash -
sudo yum install -y nodejs

# 安装 MySQL 8.0
sudo yum install mysql-server mysql -y

# 安装 Redis
sudo yum install redis -y

# 安装 Nginx
sudo yum install nginx -y

# 安装 PM2
sudo npm install -g pm2

# 启动服务
sudo systemctl enable --now mysql
sudo systemctl enable --now redis
sudo systemctl enable --now nginx
```

### 2. 配置数据库

#### MySQL 配置

```bash
# 安全初始化
sudo mysql_secure_installation

# 登录 MySQL
sudo mysql -u root -p

# 创建数据库和用户
CREATE DATABASE aisystem CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'aisystem'@'localhost' IDENTIFIED BY 'your_strong_password';
GRANT ALL PRIVILEGES ON aisystem.* TO 'aisystem'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# 优化 MySQL 配置
sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf

# 添加优化配置
[mysqld]
innodb_buffer_pool_size = 2G
innodb_log_file_size = 256M
max_connections = 200
query_cache_size = 64M
```

#### Redis 配置

```bash
# 编辑 Redis 配置
sudo vim /etc/redis/redis.conf

# 修改以下配置
bind 127.0.0.1
port 6379
requirepass your_strong_redis_password
maxmemory 1gb
maxmemory-policy allkeys-lru

# 重启 Redis
sudo systemctl restart redis
```

### 5. 配置 Nginx

#### 创建 Nginx 配置

```bash
# 创建站点配置
sudo vim /etc/nginx/sites-available/aisystem
```

```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "no-referrer-when-downgrade" always;
    add_header Content-Security-Policy "default-src 'self' http: https: data: blob: 'unsafe-inline'" always;

    # 文件上传大小限制
    client_max_body_size 50M;

    # 前端静态文件
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }

    # 后端 API
    location /api {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;

        # API 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # Gzip 压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_proxied expired no-cache no-store private must-revalidate auth;
    gzip_types text/plain text/css text/xml text/javascript application/x-javascript application/xml+rss application/javascript application/json;

    # 日志
    access_log /var/log/nginx/aisystem_access.log;
    error_log /var/log/nginx/aisystem_error.log;
}
```

#### 启用站点

```bash
# 启用站点
sudo ln -s /etc/nginx/sites-available/aisystem /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

### 6. SSL 证书配置（HTTPS）

#### 使用 Let's Encrypt

```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx -y

# 获取证书
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

# 自动续期
sudo crontab -e
# 添加以下行
0 12 * * * /usr/bin/certbot renew --quiet
```

#### 手动配置 SSL

```bash
# 创建证书目录
sudo mkdir -p /etc/nginx/ssl

# 复制证书文件
sudo cp your-cert.pem /etc/nginx/ssl/
sudo cp your-key.pem /etc/nginx/ssl/

# 设置权限
sudo chmod 600 /etc/nginx/ssl/*
```

修改 Nginx 配置支持 HTTPS：

```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yourdomain.com www.yourdomain.com;

    # SSL 配置
    ssl_certificate /etc/nginx/ssl/your-cert.pem;
    ssl_certificate_key /etc/nginx/ssl/your-key.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES256-GCM-SHA384;
    ssl_prefer_server_ciphers off;

    # 其他配置保持不变...
}
```

## 混合部署

### 使用服务器数据库 + Docker 应用

#### 1. 修改 docker-compose.yml

```yaml
# 注释掉 MySQL 和 Redis 服务
services:
  # mysql:
  #   ...

  # redis:
  #   ...

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: backend-service
    restart: always
    env_file:
      - .env
    environment:
      - NODE_ENV=production
      - PORT=3000
    ports:
      - "3000:3000"
    # 移除 depends_on 中的 mysql 和 redis

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: frontend-service
    restart: always
    environment:
      - NODE_ENV=production
    depends_on:
      - backend
    ports:
      - "8000:8000"

  nginx:
    image: nginx:1.25.3
    container_name: nginx-service
    restart: always
    depends_on:
      - backend
      - frontend
    ports:
      - "80:80"
    volumes:
      - ./infra/nginx/default.conf:/etc/nginx/conf.d/default.conf
```

#### 2. 修改环境变量

```env
# 使用服务器本地数据库
DATABASE_URL=mysql://aisystem:password@host.docker.internal:3306/aisystem
REDIS_URL=redis://:password@host.docker.internal:6379/0

# 或者使用服务器 IP
DATABASE_URL=mysql://aisystem:password@192.168.1.100:3306/aisystem
REDIS_URL=redis://:password@192.168.1.100:6379/0
```

## 安全配置

### 1. 防火墙配置

```bash
# Ubuntu/Debian
sudo ufw allow 22    # SSH
sudo ufw allow 80    # HTTP
sudo ufw allow 443   # HTTPS
sudo ufw deny 3000   # 禁止直接访问后端
sudo ufw deny 8000   # 禁止直接访问前端
sudo ufw enable

# CentOS/RHEL
sudo firewall-cmd --permanent --add-port=22/tcp
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=443/tcp
sudo firewall-cmd --reload
```

### 2. 数据库安全

```bash
# MySQL 安全配置
sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf

# 添加安全配置
[mysqld]
bind-address = 127.0.0.1
skip-networking = false
local-infile = 0
```

### 3. 文件权限

```bash
# 设置应用目录权限
sudo chown -R $USER:$USER /opt/aisystem
chmod 755 /opt/aisystem
chmod 600 /opt/aisystem/.env

# 设置日志目录权限
sudo mkdir -p /var/log/aisystem
sudo chown $USER:$USER /var/log/aisystem
chmod 755 /var/log/aisystem
```

## 监控运维

### 1. 日志管理

```bash
# 配置日志轮转
sudo vim /etc/logrotate.d/aisystem

/var/log/aisystem/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 0644 $USER $USER
    postrotate
        pm2 reloadLogs
    endscript
}
```

### 2. 监控脚本

```bash
# 创建健康检查脚本
vim /opt/aisystem/scripts/health-check.sh

#!/bin/bash
# 检查应用状态
if ! curl -f http://localhost/api/health; then
    echo "$(date): Backend service is down" >> /var/log/aisystem/health.log
    pm2 restart aisystem-backend
fi

if ! curl -f http://localhost/; then
    echo "$(date): Frontend service is down" >> /var/log/aisystem/health.log
    pm2 restart aisystem-frontend
fi

# 设置定时检查
crontab -e
*/5 * * * * /opt/aisystem/scripts/health-check.sh
```

### 3. 备份脚本

```bash
# 创建备份脚本
vim /opt/aisystem/scripts/backup.sh

#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/backup/aisystem"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
mysqldump -u aisystem -p$MYSQL_PASSWORD aisystem > $BACKUP_DIR/database_$DATE.sql
gzip $BACKUP_DIR/database_$DATE.sql

# 备份应用文件
tar -czf $BACKUP_DIR/app_$DATE.tar.gz /opt/aisystem --exclude=/opt/aisystem/node_modules --exclude=/opt/aisystem/backend/node_modules --exclude=/opt/aisystem/frontend/node_modules

# 清理旧备份（保留 30 天）
find $BACKUP_DIR -name "*.sql.gz" -mtime +30 -delete
find $BACKUP_DIR -name "*.tar.gz" -mtime +30 -delete

# 设置定时备份
crontab -e
0 2 * * * /opt/aisystem/scripts/backup.sh
```

### 4. 更新脚本

```bash
# 创建更新脚本
vim /opt/aisystem/scripts/update.sh

#!/bin/bash
cd /opt/aisystem

# 备份当前版本
cp .env .env.backup

# 拉取最新代码
git pull origin main

# 安装依赖
npm install
cd backend && npm install && npm run build
cd ../frontend && npm install && npm run build
cd ..

# 执行数据库迁移
cd backend && npx prisma migrate deploy && cd ..

# 重启应用
pm2 restart all

echo "Update completed at $(date)"
```

## 故障处理

### 1. 应用无法启动

```bash
# 检查 PM2 状态
pm2 status

# 查看错误日志
pm2 logs aisystem-backend --lines 100
pm2 logs aisystem-frontend --lines 100

# 检查端口占用
netstat -tulpn | grep :3000
netstat -tulpn | grep :8000

# 重启应用
pm2 restart all
```

### 2. 数据库连接失败

```bash
# 检查 MySQL 状态
sudo systemctl status mysql

# 测试数据库连接
mysql -u aisystem -p -h localhost aisystem

# 查看 MySQL 日志
sudo tail -f /var/log/mysql/error.log

# 重启 MySQL
sudo systemctl restart mysql
```

### 3. Nginx 配置错误

```bash
# 测试 Nginx 配置
sudo nginx -t

# 查看 Nginx 日志
sudo tail -f /var/log/nginx/error.log
sudo tail -f /var/log/nginx/aisystem_error.log

# 重启 Nginx
sudo systemctl restart nginx
```
