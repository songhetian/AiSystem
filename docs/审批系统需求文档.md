# 审批系统需求文档（PRD）

# 1. 文档概述

## 1.1 文档目的

本文档明确审批系统的核心功能需求、交互逻辑及约束条件，为研发、测试、设计等相关人员提供统一的需求基准，确保系统开发符合业务场景及用户使用需求，同时作为产品迭代、需求验收的核心依据。

## 1.2 适用范围

本文档适用于审批系统的产品设计、研发开发、测试验收、运维部署等全流程相关人员，覆盖系统所有核心模块及功能点。

## 1.3 核心目标

1. 实现审批模板的灵活配置与高效管理，支持多场景、多维度的模板定制，减少重复配置成本；

2. 提供可视化、可拖拽的审批流程编排能力，满足不同业务场景下的流程需求，提升流程配置效率；

3. 优化审批操作流程，明确审批节点权责，实现审批全流程可追溯、可管理；

4. 提供完善的辅助功能，提升审批效率，降低用户操作成本，保障审批流程顺畅推进；

5. 新增费用、报销、采购、收支记录及数据统计功能，实现企业费用管控、采购管理、收支核算全流程数字化，提升管理效率；

6. 补充对应拖拽交互及异常处理，确保新增功能操作流畅、异常可管控。

# 2. 核心功能需求

## 2.1 审批模板管理模块

核心目标：实现审批模板的全生命周期管理，支持模板的新增、编辑、删除、启用/禁用、复制，满足不同平台、不同部门的专属模板需求。

### 2.1.1 模板配置

1. 支持新增多种类型审批模板，包括但不限于请假审批、报销审批、采购审批等，可根据业务需求扩展模板类型；

2. 模板配置核心字段：

- 基础信息：模板名称（唯一，不可重复）、审批类型（关联预设类型，支持自定义新增类型）；

- 表单配置：支持自定义表单字段，可添加文本框、下拉框、单选框、复选框、日期选择器等多种表单组件，配置字段名称、提示语、是否必填、默认值等属性；

- 关联配置：支持关联平台ID、部门ID，可按“平台+部门”组合配置专属模板，仅该平台该部门用户可使用该模板发起审批；

3. 配置完成后支持预览表单样式，确认无误后保存模板。

### 2.1.2 模板管理

1. 编辑模板：支持修改模板的所有配置信息（基础信息、表单字段、关联配置），编辑后需重新保存生效，已发起的审批不受模板修改影响；

2. 删除模板：支持删除未被使用（无关联审批记录）的模板，若模板已被使用，需提示“该模板存在关联审批记录，不可删除”；

3. 模板启用/禁用：支持手动切换模板状态，启用后用户可使用该模板发起审批；禁用后，该模板不可被选择发起审批，已发起的审批仍可正常推进。

### 2.1.3 模板复制

1. 支持复制现有已保存的审批模板，复制后生成新模板（默认名称为“原模板名称+副本”）；

2. 复制后的模板保留原模板的所有配置信息（表单字段、关联配置等），用户可直接编辑修改，减少重复配置操作。

## 2.2 审批流程配置模块

核心目标：实现审批流程的可视化配置，支持多节点、分支节点编排，明确每个节点的审批规则，确保审批流程符合业务逻辑。

### 2.2.1 流程节点配置

1. 支持配置多节点审批流程，例如“申请人→部门负责人→HR→总经理”，节点顺序可灵活调整；

2. 支持配置分支节点，根据审批表单中的字段条件（如报销金额、采购数量等）设置分支规则，例如“金额>1000元需总经理审批，否则HR审批”；

3. 支持添加抄送人节点，抄送人仅查看审批进度及详情，不参与审批操作，可配置抄送人接收消息的时机（审批发起时、审批通过时、审批驳回时）。

### 2.2.2 节点详情配置

1. 审批人分配：为每个审批节点分配审批人，支持单个或多个审批人；多个审批人时，支持选择“或签”（任意一人审批通过即可进入下一节点）或“会签”（所有审批人全部通过方可进入下一节点）模式；

2. 审批时限配置：为每个节点设置审批时限（如24小时、3个工作日），超时后系统自动发送超时提醒，提醒频率可配置；

3. 节点描述：支持为每个节点添加描述信息（如“部门负责人审核申请的合理性”），方便审批人了解节点审批职责。

### 2.2.3 流程预览

1. 流程配置完成后，支持预览整个审批流程的结构，包括节点顺序、分支条件、审批人、审批时限等信息；

2. 预览时可模拟不同条件下的流程走向（如满足分支条件时的节点流转），确认流程配置无误后，点击保存生效。

## 2.3 审批操作模块

核心目标：实现审批全流程的操作管理，清晰划分审批场景，支持审批人、申请人的各类操作，确保审批流程顺畅推进。

### 2.3.1 审批列表展示

系统按审批场景划分三个核心列表，支持多条件筛选，提升用户查找效率：

1. 我的审批：展示当前用户发起的所有审批记录，支持查看每条审批的状态（待审批、审批中、已通过、已驳回）、审批进度（当前节点、已完成节点）、审批意见，可按平台、部门、审批类型、日期范围筛选；

2. 待我审批：展示当前用户需要处理的所有审批申请，支持按审批类型、发起日期、紧急程度排序，每条申请显示核心信息（申请人、申请类型、发起时间、表单关键内容）；

3. 已审批：展示当前用户已处理（同意、驳回、转审）的所有审批记录，支持查看完整审批流程、所有节点的审批意见及最终审批结果，可按处理时间、审批结果筛选。

### 2.3.2 审批操作（同意/驳回/转审）

1. 同意：审批人点击“同意”，系统自动将审批流转至下一节点；若当前节点为最后一个审批节点，审批状态更新为“已通过”，并通知申请人及相关抄送人；

2. 驳回：审批人点击“驳回”，需填写驳回原因（必填，支持文本输入，可预设常用驳回原因选项），审批将返回至申请人，申请人可查看驳回原因，修改表单内容后重新提交审批；

3. 转审：审批人可将当前审批任务转交给其他人员处理，需选择转审人（支持模糊搜索）、填写转审原因（必填），转审后，当前审批人不再参与该审批流程，转审人成为该节点的审批人，系统通知转审人处理审批。

## 2.4 辅助功能模块

核心目标：提升审批效率，降低用户操作成本，保障审批流程不中断，实现审批记录的可追溯、可导出。

### 2.4.1 审批提醒

1. 提醒类型：待审批任务提醒、审批超时提醒、审批状态变更提醒（如审批通过、驳回、转审）；

2. 提醒方式：系统内消息提醒（首页通知中心）+ 短信提醒（可配置是否开启）；

3. 提醒频率：支持配置超时提醒频率（如每6小时提醒一次、每天提醒一次），避免审批遗漏。

### 2.4.2 审批搜索

支持多条件组合搜索审批记录，搜索条件包括：申请人、审批类型、审批状态、发起日期范围、关联平台、关联部门，搜索结果支持按发起时间、审批进度排序。

### 2.4.3 审批导出

1. 支持导出指定条件下的审批记录（可选择导出“我的审批”“待我审批”“已审批”或全部审批）；

2. 导出内容：包含审批基础信息（申请人、发起时间、审批类型、审批状态）、审批详情（表单字段内容）、审批意见（各节点审批人、意见、处理时间）、审批流程（节点流转记录）；

3. 导出格式：支持Excel格式，导出文件名称默认包含“审批记录+导出日期”。

## 2.5 费用类型管理模块

核心目标：实现费用类型的规范化管理，支持多维度专属配置，为报销管理提供基础分类依据，确保费用核算清晰可追溯。

### 2.5.1 类型配置

1. 支持新增多种费用类型，包括但不限于差旅费、办公费、业务招待费等，可根据企业业务需求扩展类型；

2. 类型配置核心字段：

- 基础信息：类型名称（唯一，不可重复）、类型编码（唯一标识，支持自定义规则生成）、描述（简要说明该费用类型的适用场景）；

- 关联配置：支持关联平台ID、部门ID，可按“平台+部门”组合配置专属费用类型，仅该平台该部门用户可在报销时选择该类型；

3. 配置完成后支持预览类型详情，确认无误后保存生效。

### 2.5.2 类型管理

1. 编辑类型：支持修改费用类型的所有配置信息（基础信息、关联配置），编辑后需重新保存生效，已关联的报销记录不受类型修改影响；

2. 删除类型：删除前系统自动校验该类型是否关联报销记录，若已关联，提示“该费用类型已关联报销记录，不可删除”；若未关联，可直接删除；

3. 类型启用/禁用：支持手动切换费用类型状态，启用后用户可在报销申请中选择该类型；禁用后，该类型不可被选择，已关联该类型的历史报销记录不受影响。

## 2.6 报销管理模块

核心目标：实现报销申请、审批、跟踪、打款全流程管理，规范报销流程，提升报销效率，确保报销数据可追溯、可管控。

### 2.6.1 报销申请

1. 员工可发起报销申请，核心操作包括：选择已启用的费用类型、填写报销金额（支持保留两位小数，需大于0）、填写报销事由（必填，清晰说明报销用途）、上传报销附件（发票、凭证等）；

2. 可选关联：支持关联加班记录、出差记录（关联后自动同步相关信息，无需重复填写）；

3. 关联配置：需选择关联平台ID、部门ID；若为电商相关报销，需关联对应店铺ID，便于按店铺核算费用；

4. 申请提交：提交前系统校验必填项（费用类型、报销金额、报销事由），校验通过后提交至对应审批流程，提交后可查看审批进度。

### 2.6.2 报销审批

1. 报销申请提交后，自动关联预设的审批流程（可关联报销专属审批模板），按流程节点依次审批；

2. 审批人可查看报销申请的完整详情，包括费用类型、金额、事由、关联记录，可在线预览、下载报销附件，核实报销合理性；

3. 审批操作：支持同意、驳回、转审操作，操作逻辑与通用审批一致，需填写审批意见（驳回、转审需填写对应原因）。

### 2.6.3 报销管理

1. 状态管理：报销审批通过后，系统自动标记为“待打款”；财务完成打款后，由管理员或财务人员更新状态为“已打款”，并记录打款时间、打款方式；

2. 申请操作：报销申请未进入审批流程（未被任何审批人处理）前，申请人可撤回申请；撤回后可修改申请内容（费用类型、金额、附件等），修改完成后重新提交；

3. 记录查询：支持按申请人、费用类型、审批状态、日期范围、平台、部门、店铺筛选报销记录，查看完整流程及打款信息。

## 2.7 采购管理模块

核心目标：实现采购申请、审批、跟踪、完成全流程管理，规范采购流程，把控采购成本，确保采购需求有序落地。

### 2.7.1 采购申请

1. 员工可发起采购申请，核心填写内容包括：采购物品（名称、规格型号等）、采购数量（需为正整数）、单价（支持保留两位小数）、采购原因（必填，说明采购用途及必要性）、预计金额（系统自动计算数量×单价，可手动调整）；

2. 附件上传：支持上传采购需求附件（报价单、采购方案等），便于审批人核实采购合理性；

3. 关联配置：需选择关联平台ID、部门ID；若为电商店铺采购，需关联对应店铺ID，明确采购归属；

4. 提交校验：提交前系统校验必填项及数据合理性（数量、单价为正数），校验通过后提交至对应审批流程。

### 2.7.2 采购审批与执行

1. 采购申请提交后，关联预设的采购审批流程，按节点依次审批，审批人可查看采购详情、附件，添加审批意见，操作逻辑与通用审批一致；

2. 状态更新：审批通过后，系统自动标记为“待采购”；采购人员完成采购后，更新采购状态为“已完成”，并填写实际采购金额、采购完成时间、供应商信息等；

3. 异常处理：若采购过程中出现变更（如采购数量、单价调整），由采购申请人发起修改申请，重新走审批流程；若采购取消，需发起取消申请，说明取消原因，审批通过后标记为“已取消”。

### 2.7.3 采购跟踪

1. 进度查看：所有用户可查看自己发起或参与审批的采购申请进度，包括当前审批节点、处理人、处理时间，以及采购执行状态（待采购、采购中、已完成、已取消）；

2. 申请操作：采购申请未进入审批流程前，申请人可撤回申请；审批过程中，若未被最终审批人同意，可发起修改申请，修改后重新提交审批。

## 2.8 收支记录模块

核心目标：实现公司收入、支出的规范化记录与管理，自动同步相关业务数据，确保收支数据准确、可追溯，为财务核算提供支撑。

### 2.8.1 收入记录

1. 支持手动新增收入记录，核心填写内容包括：收入金额（支持保留两位小数，大于0）、收入来源（如营收、回款、其他收入等，可自定义）、收入日期、备注（简要说明收入情况）；

2. 关联配置：需选择关联平台ID、部门ID；若为电商店铺收入，需关联对应店铺ID，便于按店铺核算收入；

3. 记录校验：提交前系统校验收入金额、收入日期等核心字段，确保数据合理，提交后不可随意修改（需管理员权限）。

### 2.8.2 支出记录

1. 支出记录分为两种创建方式：手动新增、自动同步；

- 自动同步：关联报销打款、采购付款记录，当报销标记为“已打款”、采购标记为“已付款”时，系统自动同步金额、日期、平台、部门、店铺等信息，生成支出记录，无需手动录入；

- 手动新增：支持手动录入其他支出（如房租、水电费等），填写内容与收入记录一致，需关联对应平台、部门、店铺（可选）；

2. 支出记录关联对应业务单据（报销单、采购单），点击可查看单据详情，确保支出可追溯。

### 2.8.3 记录管理

1. 操作权限：新增、编辑、删除收支记录需对应权限，其中删除操作仅管理员可执行；编辑记录时，需保留修改日志，记录修改人、修改时间、修改内容；

2. 搜索筛选：支持多条件搜索收支记录，筛选条件包括平台、部门、店铺、收入/支出类型、日期范围、金额范围；

3. 记录导出：支持导出指定条件下的收支记录，导出格式为Excel，包含所有字段信息，便于财务对账。

## 2.9 数据统计模块

核心目标：对报销、采购、收支数据进行多维度统计分析，生成可视化图表，为企业管理决策提供数据支撑，实现数据可看、可用、可导出。

### 2.9.1 报销统计

1. 统计维度：支持按费用类型、部门、时间段（日、周、月、季度、年）、平台、店铺进行多维度统计；

2. 统计内容：统计对应维度下的报销金额（总金额、平均金额）、报销笔数、通过率、驳回率；

3. 可视化展示：生成柱状图（对比不同维度数据）、饼图（展示费用类型占比），支持图表缩放、切换，直观呈现数据分布；

4. 数据导出：支持导出统计数据及图表，导出格式为Excel、图片，便于汇报使用。

### 2.9.2 采购统计

1. 统计维度：支持按采购物品、部门、时间段、平台、店铺进行多维度统计；

2. 统计内容：统计对应维度下的采购金额（预计金额、实际金额）、采购数量、采购完成率、采购周期；

3. 可视化展示：生成柱状图、折线图（展示采购趋势），支持对比预计与实际采购数据，便于成本管控；

4. 数据导出：支持导出统计数据及图表，格式与报销统计一致。

### 2.9.3 收支统计

## 4.0 异常处理需求

核心目标：处理系统运行及用户操作过程中的各类异常场景，给出明确提示、保障系统稳定性，减少用户操作困扰，确保审批流程不中断。

### 4.0.1 操作异常处理

1. 表单提交异常：当表单填写不完整、字段格式错误（如日期格式、数值格式）、必填项未填写时，系统实时提示异常原因，标注异常字段，禁止提交，直至用户修正；

2. 审批操作异常：审批人同时操作同一审批任务（如同时同意/驳回），系统锁定操作权限，提示“当前审批任务正在处理，请稍后再试”，避免并发操作冲突；

3. 模板/流程配置异常：配置模板时未关联平台/部门、配置流程时未分配审批人、分支条件逻辑冲突（如同时满足两个互斥分支），系统提示具体异常点，禁止保存，引导用户修正；

4. 转审/驳回异常：转审人无审批权限、驳回时未填写驳回原因，系统提示异常，阻止操作，并给出修正建议（如“请选择有审批权限的用户作为转审人”）；

5. 费用类型操作异常：新增费用类型时名称/编码重复、删除已关联报销记录的类型，系统提示异常并阻止操作；禁用已被大量使用的费用类型时，提示“该类型已被多个报销记录关联，禁用后将影响相关记录查看，是否确认禁用”；

6. 报销/采购操作异常：报销金额为负数、采购数量为0或负数、附件上传超出大小限制，系统提示异常并阻止提交；报销/采购申请已审批后，申请人试图撤回或修改，提示“该申请已进入审批流程，不可撤回/修改”；

7. 收支记录操作异常：收入/支出金额为负数、未关联平台/部门（必填）、普通用户试图删除收支记录，系统提示异常并阻止操作；编辑已同步生成的支出记录（如报销打款同步），提示“该记录为系统自动同步，不可手动编辑”；

8. 拖拽操作异常：拖拽节点至非法位置、重复拖拽同一人员、拖拽禁用列至隐藏区域，系统提示异常并阻止操作，给出修正建议；拖拽上传失败、拖拽过程中网络中断，提示异常并支持重新操作。

### 4.0.2 系统异常处理

1. 系统崩溃/卡顿：系统突发崩溃或操作卡顿，自动保存当前用户操作进度（如模板配置、流程编排、审批意见、报销/采购申请内容），恢复后提示用户“操作已自动保存，可继续编辑”；

2. 数据加载异常：审批列表、模板列表、流程节点、报销/采购/收支记录加载失败时，显示“数据加载失败，请刷新页面重试”，提供刷新按钮，同时记录异常日志，便于运维排查；

3. 提醒发送异常：短信提醒发送失败（如手机号错误、运营商限制），系统自动切换为系统内消息提醒，同时提示管理员“部分短信提醒发送失败，请检查手机号配置”；
