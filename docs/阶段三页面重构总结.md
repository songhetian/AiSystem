## 💡 重构经验总结

### 1. 组件替换策略

| 原组件 | 新组件 | 优势 |
|--------|--------|------|
| @ant-design/pro-layout PageContainer | @/components/layout PageContainer | 更灵活、毛玻璃效果 |
| Ant Design Card | @/components/layout SectionCard | 可折叠、区块化 |
| 自定义筛选组件 | @/components/business FilterBar | 统一体验、响应式 |
| 自定义表格 | @/components/ui Table | 毛玻璃、多密度 |
| 自定义模态框 | @/components/ui Modal/Drawer | 毛玻璃、动画 |

### 2. 类型定义规范

```tsx
// ✅ 好的做法：定义完整的接口
interface OperationLog {
  id: number;
  userId: number;
  username: string;
  name: string;
  module: string;
  action: string;
  // ... 其他字段
}

// ❌ 不好的做法：使用any
const data: any[] = [];
```

### 3. 格式化工具使用

```tsx
// ✅ 好的做法：使用工具函数
import { formatDate, formatNumber } from '@/utils/format';
{formatDate(record.createdAt)}
{formatNumber(record.amount)}

// ❌ 不好的做法：手动格式化
{new Date(record.createdAt).toLocaleString()}
{record.amount.toLocaleString()}
```

### 4. 状态标签使用

```tsx
// ✅ 好的做法：使用StatusTag
<StatusTag status="success" text="成功" />
<StatusTag status="error" text="失败" />

// ❌ 不好的做法：纯文本
<span style={{ color: 'green' }}>成功</span>
```
