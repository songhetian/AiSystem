# P0级功能测试指南

## 测试前准备

### 1. 启动数据库
```bash
# 确保PostgreSQL数据库正在运行
# 检查.env文件中的数据库连接配置
```

### 2. 应用数据库迁移
```bash
cd backend
npm run prisma:migrate
```

### 3. 运行seed脚本（更新权限数据）
```bash
cd backend
npm run prisma:seed
```

### 4. 启动后端服务
```bash
cd backend
npm run start:dev
```

### 5. 启动前端服务
```bash
cd frontend
npm run dev
```

## JWT身份认证测试

### 测试1: 正常登录
**步骤**:
1. 打开浏览器访问前端地址（通常是 http://localhost:8000）
2. 输入用户名：`admin`
3. 输入密码：`Admin123456`
4. 点击登录按钮

**预期结果**:
- ✅ 登录成功，跳转到首页
- ✅ 浏览器localStorage中存储了Token
- ✅ 后端返回用户信息和Token
- ✅ 登录日志记录成功

**验证方法**:
- 打开浏览器开发者工具 → Application → Local Storage → 查看是否有 `token` 和 `userInfo`
- 打开浏览器开发者工具 → Network → 查看登录请求响应

- ✅ 登录日志记录锁定状态

**验证方法**:
- 查看页面错误提示
- 查看浏览器开发者工具 → Network → 查看登录请求响应

### 测试4: Token验证

### 测试5: Token过期
**步骤**:
1. 登录成功后
2. 修改localStorage中的Token为过期Token（或等待Token过期）
3. 访问任意业务接口

**预期结果**:
- ✅ 接口返回401错误
- ✅ 前端自动跳转到登录页
- ✅ 显示"登录已过期，请重新登录"提示

**验证方法**:
- 打开浏览器开发者工具 → Network → 查看接口响应状态码

---

### 测试6: Token刷新
**步骤**:
1. 登录成功后
2. 等待Token即将过期（提前5分钟）
3. 访问任意业务接口

**预期结果**:
- ✅ 响应头包含 `X-Refresh-Token: true`
- ✅ 前端自动调用刷新接口
- ✅ 新Token存储到localStorage
- ✅ 旧Token加入黑名单

**验证方法**:
- 打开浏览器开发者工具 → Network → 查看响应头
- 查看localStorage中的Token是否更新
