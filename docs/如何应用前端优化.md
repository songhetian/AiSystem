## 🚀 应用步骤

### 步骤1：应用样式系统

#### 1.1 复制样式文件

将以下文件复制到项目中：
```
frontend/src/styles/
├── variables.less
├── mixins.less
├── theme.less
├── animations.less
└── global.less
```

#### 1.2 在主入口引入全局样式

在 `frontend/src/app.tsx` 或 `frontend/src/index.tsx` 中引入：

```tsx
// 引入全局样式
import '@/styles/global.less';
```

#### 1.3 配置Less变量

在 `.umirc.ts` 或 `config/config.ts` 中配置Less：

```typescript
export default {
  // ... 其他配置
  theme: {
    // 引入主题变量
    '@import': '~@/styles/theme.less',
  },
  lessLoader: {
    modifyVars: {
      // 可以在这里覆盖变量
    },
  },
};
```

## 🎯 优化建议

### 1. 渐进式重构

不要一次性重构所有页面，建议：
1. 先重构1-2个简单页面，熟悉新组件
2. 再重构复杂页面
3. 最后重构特殊页面（大屏等）

### 2. 保留备份

重构前务必备份原文件：
```bash
# 创建备份
cp index.tsx index.backup.tsx

# 或使用git分支
git checkout -b refactor/page-name
```

### 3. 充分测试

每重构一个页面都要充分测试：
- 功能测试
- 视觉测试
- 性能测试
- 兼容性测试

### 4. 团队协作

- 与团队成员沟通重构计划
- 统一代码风格
- 及时更新文档
- 代码审查

## 🔧 常见问题

### Q1: 样式不生效怎么办？

**A**: 检查以下几点：
1. 是否正确引入了 `global.less`
2. 是否配置了Less loader
3. 是否有样式冲突
4. 浏览器缓存是否清除

### Q2: 组件找不到怎么办？

**A**: 检查以下几点：
1. 组件文件是否正确复制
2. 导入路径是否正确
3. 是否配置了路径别名（@）

### Q3: TypeScript报错怎么办？

**A**: 检查以下几点：
1. 类型定义文件是否存在
2. 类型导入是否正确
3. 是否需要安装类型包

### Q4: 毛玻璃效果不显示？

**A**: 检查以下几点：
1. 是否添加了 `glass` prop
2. 浏览器是否支持 `backdrop-filter`
3. 是否有其他样式覆盖

### Q5: 性能问题怎么办？

**A**: 优化建议：
1. 使用 `React.memo` 优化组件
2. 使用 `useMemo` 优化计算
3. 使用虚拟滚动处理大数据
4. 懒加载组件
