## 一、优化目标

### 1.1 核心目标
- ✅ 从"AI演示"转向"企业实战"风格
- ✅ 采用毛玻璃效果和深度感设计
- ✅ 提升信息密度，优化布局
- ✅ 统一钉钉风格的简洁高效设计
- ✅ 组件化开发，所有组件单独设置

### 1.2 设计原则
1. **去"样板"化**：消除Ant Design Pro的默认廉价感
2. **高吞吐量**：优化布局以展示更多核心业务数据
3. **实战质感**：引入毛玻璃效果、深邃配色与微动效
4. **组件复用**：所有UI组件单独开发，不在页面中直接写样式
5. **钉钉风格**：简洁、高效、易用

## 四、组件开发规范

### 4.1 组件开发原则

1. **单一职责**：每个组件只负责一个功能
2. **高内聚低耦合**：组件内部高度内聚，组件之间低耦合
3. **可配置**：通过props配置组件的外观和行为
4. **可复用**：组件可在多个页面中复用
5. **类型安全**：使用TypeScript定义组件的props和state类型

### 4.2 组件开发模板

```typescript
// components/ui/Card/types.ts
export interface CardProps {
  /** 卡片标题 */
  title?: React.ReactNode;
  /** 卡片内容 */
  children: React.ReactNode;
  /** 是否使用毛玻璃效果 */
  glass?: boolean;
  /** 阴影大小 */
  shadow?: 'sm' | 'md' | 'lg' | 'xl' | '2xl';
  /** 圆角大小 */
  radius?: 'sm' | 'base' | 'md' | 'lg' | 'xl' | '2xl';
  /** 额外的类名 */
  className?: string;
  /** 额外的样式 */
  style?: React.CSSProperties;
  /** 点击事件 */
  onClick?: () => void;
}

// components/ui/Card/index.tsx
import React from 'react';
import classNames from 'classnames';
import { CardProps } from './types';
import styles from './index.module.less';

export const Card: React.FC<CardProps> = ({
  title,
  children,
  glass = false,
  shadow = 'md',
  radius = 'lg',
  className,
  style,
  onClick,
}) => {
  const cardClass = classNames(
    styles.card,
    {
      [styles.glass]: glass,
      [styles[`shadow-${shadow}`]]: shadow,
      [styles[`radius-${radius}`]]: radius,
    },
    className
  );

  return (
    <div className={cardClass} style={style} onClick={onClick}>
      {title && <div className={styles.cardTitle}>{title}</div>}
      <div className={styles.cardContent}>{children}</div>
    </div>
  );
};

// components/ui/Card/index.module.less
@import '@/styles/variables.less';
@import '@/styles/mixins.less';

.card {
  background: #fff;
  border-radius: @radius-lg;
  padding: @spacing-6;
  transition: all 0.3s ease;

  &.glass {
    .glassmorphism();
  }

  &.shadow-sm {
    box-shadow: @shadow-sm;
  }

  &.shadow-md {
    box-shadow: @shadow-md;
  }

  &.shadow-lg {
    box-shadow: @shadow-lg;
  }

  &.shadow-xl {
    box-shadow: @shadow-xl;
  }

  &.shadow-2xl {
    box-shadow: @shadow-2xl;
  }

  &.radius-sm {
    border-radius: @radius-sm;
  }

  &.radius-base {
    border-radius: @radius-base;
  }

  &.radius-md {
    border-radius: @radius-md;
  }

  &.radius-lg {
    border-radius: @radius-lg;
  }

  &.radius-xl {
    border-radius: @radius-xl;
  }

  &.radius-2xl {
    border-radius: @radius-2xl;
  }

  &:hover {
    transform: translateY(-2px);
    box-shadow: @shadow-xl;
  }
}

.cardTitle {
  font-size: @font-size-lg;
  font-weight: @font-weight-semibold;
  color: @primary-900;
  margin-bottom: @spacing-4;
}

.cardContent {
  color: @primary-700;
}
```

## 六、优化重点

### 6.1 毛玻璃效果应用场景

1. **卡片组件**：所有卡片默认使用毛玻璃效果
2. **模态框**：模态框背景使用毛玻璃效果

4. **侧边栏优化**：在关键页面侧边引入实时日志流

1. **简洁布局**：采用钉钉风格的简洁布局
