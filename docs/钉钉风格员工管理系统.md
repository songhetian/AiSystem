## 一、文档概述

### 1\.1 系统定位

本系统1:1对标钉钉员工管理模块，严格遵循钉钉员工字段规范，新增身份证正反面存储、员工全生命周期履历管理（在职时长、部门履历、复职记录）及学历信息管理模块，实现企业员工信息标准化、履历可追溯、学历信息可管理、权限可控、数据安全的员工全生命周期管理。

### 1\.2 适用对象

- 企业HR、管理员：员工录入、编辑、审批、履历查询、学历信息维护

- 部门主管：查看本部门员工信息及学历、履历情况

- 员工本人：查看个人信息、履历及学历备案信息

### 1\.3 核心扩展点（基于钉钉原生）

1. 保留钉钉全部标准员工字段，不做任何自定义删减，确保与钉钉员工管理逻辑、字段含义完全一致

2. 新增：身份证正面、身份证反面图片存储及预览功能

3. 新增：员工履历模块（在职时长自动计算、部门调动记录、首次入职/复职/离职历史）

4. 新增：学历信息管理模块（学历层次、毕业院校、专业、毕业时间、学历证书备案）

## 二、功能模块总览

员工管理系统

    - 组织架构管理（部门/子部门，支持多级嵌套）

    - 角色权限管理（同钉钉权限逻辑，区分不同角色操作范围）

    - 学历字典管理（维护学历层次、专业分类等基础数据）

- 员工信息管理（核心）

    - 身份证正反面上传、预览、存储（支持常见图片格式，加密存储）

## 三、数据库设计（严格对标钉钉 \+ 扩展字段，无代码）

### 3\.1 设计规范

1. 字段命名、含义、逻辑完全对齐钉钉员工管理模块，确保与钉钉数据结构兼容

2. 非空、唯一、默认值严格遵循企业级系统设计规范，保障数据完整性和一致性

3. 履历表采用流水表设计，记录员工每一次信息变更，不可修改、不可删除，确保履历可追溯

4. 学历信息采用关联设计，支持员工多学历备案（如本科、硕士等），同时关联基础学历字典

5. 支持多次入职/离职（复职员工），履历表完整记录每一次入职、离职、复职流程

6. 身份证图片、学历证书图片采用URL存储，关联文件存储服务，确保文件安全

### 3\.2 核心数据表说明（无代码，仅说明表结构、字段含义）

#### 3\.2\.1 部门表（对标钉钉组织架构）

用于存储企业所有部门信息，支持多级部门嵌套，与钉钉组织架构逻辑完全一致，核心字段包括部门ID、上级部门ID、部门名称、排序、状态、创建时间、更新时间，用于关联员工所属部门，支撑组织架构展示和权限管控。

#### 3\.2\.2 岗位表（钉钉标准）

用于存储企业所有岗位信息，关联所属部门，与钉钉岗位管理逻辑一致，核心字段包括岗位ID、岗位名称、所属部门ID、排序、状态，用于记录员工当前岗位，支撑员工信息展示和岗位筛选。

#### 3\.2\.3 学历字典表（新增）

用于维护企业常用的学历基础数据，统一学历标准，避免录入混乱，核心字段包括字典ID、学历层次（如小学、初中、高中、专科、本科、硕士、博士）、专业分类（如计算机类、文史类、理工类等）、排序、状态，用于关联员工学历信息，支撑学历筛选和标准化管理。

#### 3\.2\.4 员工主表（核心：钉钉标准字段 \+ 身份证 \+ 学历扩展）

本表严格按照钉钉员工字段设计，无自定义删减，仅新增身份证相关扩展字段和学历关联字段，是员工信息的核心存储表，核心字段分类如下：

- 基础标识字段：员工ID、员工工号（对应钉钉userid，唯一）、姓名、头像

- 基础个人信息（钉钉标准）：性别、手机号（登录账号，唯一）、邮箱、出生日期

- 入职相关信息（钉钉标准）：首次入职时间、当前入职时间（复职用）、离职时间、员工类型、在职状态

- 组织关联信息（钉钉标准）：当前部门ID、当前岗位ID、直属主管工号

- 证件扩展信息（新增）：身份证号、身份证正面图片URL、身份证反面图片URL

- 学历关联信息（新增）：最高学历ID（关联学历字典表）、学历备案状态

- 其他信息（钉钉标准）：住址、紧急联系人、紧急联系电话、备注

- 系统字段：状态（正常/禁用）、创建人、创建时间、更新时间

#### 3\.2\.5 员工学历表（新增）

用于存储员工的学历详细信息，支持多学历备案，关联员工主表和学历字典表，核心字段包括学历记录ID、员工工号、学历层次ID（关联学历字典）、专业、毕业院校、毕业时间、学历证书URL、备案时间、备注，用于详细记录员工的学历情况，支撑学历查询和备案管理。

#### 3\.2\.6 员工履历表（核心扩展：在职/部门/复职全记录）

流水表，记录员工所有历史变动，不可修改、不可删除，核心字段包括履历ID、员工工号、履历类型（入职、复职、离职、部门调动）、操作时部门ID、操作时岗位ID、操作时间、累计在职天数、本次在职天数、备注（调动原因/离职原因等）、创建时间，用于完整追溯员工在公司的所有变动记录，自动计算在职时长。

## 五、核心功能详细设计

### 5\.1 员工信息管理（钉钉标准 \+ 学历/身份证扩展）

#### 5\.1\.1 功能列表

- 新增员工：严格按照钉钉员工录入字段设计，新增身份证正反面上传、学历信息录入（支持多学历添加），所有必填字段与钉钉保持一致

- 批量导入：支持Excel批量导入员工信息，包含基础信息、身份证信息、学历信息，导入后自动校验字段合法性，生成导入日志

- 编辑员工信息：支持修改钉钉标准字段、身份证图片替换、学历信息编辑（新增/删除/修改学历记录），修改后自动记录日志

- 启用/禁用/离职：与钉钉操作逻辑一致，禁用员工无法登录系统，离职员工自动更新在职状态和离职时间，生成离职履历

- 身份证管理：支持身份证正面、反面图片上传（支持JPG、PNG格式，限制文件大小）、预览、删除，图片采用加密存储，仅有权限人员可见

- 学历管理：支持新增学历记录、编辑已有学历、删除无效学历，关联学历字典，确保学历层次、专业标准化，支持学历证书上传备案

- 信息修改日志：所有员工信息、学历信息、身份证信息的修改操作，均记录修改人、修改时间、修改前内容、修改后内容，确保可追溯

#### 5\.1\.2 字段必填规则（同钉钉，新增学历相关必填项）

钉钉标准必填项：员工工号、姓名、手机号、首次入职时间、当前部门ID

新增必填项：身份证号（新增员工时必填）、最高学历ID（新增员工时必填）

可选项：身份证图片、学历证书图片、邮箱、出生日期、紧急联系人等（与钉钉保持一致）

### 5\.2 员工履历管理（系统核心扩展）

#### 5\.2\.1 履历自动生成规则

1. 入职：员工新增并提交后，自动生成“入职”类型履历，记录首次入职时间、当前部门、当前岗位，初始化累计在职天数和本次在职天数为0，后续按自然日自动累加。

2. 部门调动：员工部门修改并提交后，自动生成“部门调动”类型履历，记录调动前部门、调动后部门、调动时间、调动原因（可选），在职时长继续累加，不中断。

3. 复职：离职员工办理复职手续后，更新员工主表的当前入职时间和在职状态，自动生成“复职”类型履历，记录复职时间、复职后部门、复职后岗位，本次在职天数重新开始计算，累计在职天数保留历史数据并继续累加。

4. 离职：员工办理离职手续后，更新员工主表的离职时间和在职状态，自动生成“离职”类型履历，记录离职时间、离职原因（可选），自动计算本次在职天数和累计在职天数，定格当前在职时长数据。

#### 5\.2\.2 履历展示（前端时间轴）

采用时间轴形式直观展示员工所有履历记录，按时间倒序排列，每条记录包含以下信息：操作时间、履历类型、操作时部门、操作时岗位、在职时长（本次/累计）、备注，示例如下：

- 2024\-12\-20 部门调动：技术部 → 运营部，岗位：Java开发工程师 → 运营专员，本次在职186天，累计在职551天，备注：个人发展调整

- 2024\-05\-20 复职：运营部，岗位：运营专员，本次在职186天，累计在职551天，备注：个人原因复职

- 2024\-02\-09 离职：技术部，岗位：Java开发工程师，本次在职365天，累计在职365天，备注：个人职业规划调整

- 2023\-02\-10 入职：技术部，岗位：Java开发工程师，本次在职0天，累计在职0天，备注：新员工入职

#### 5\.2\.3 在职时长自动计算

- 本次在职时长：当前入职时间（复职员工）或首次入职时间（未离职且未复职员工）至当前系统时间的自然日天数，自动实时更新。

- 累计在职时长：员工所有入职周期的在职天数之和，离职时定格，复职后继续累加，自动计算并更新至履历表。

- 展示格式：统一采用“X年X月X天”格式，不足1年的显示“X月X天”，不足1月的显示“X天”，确保直观易懂。

### 5\.3 学历管理功能（新增核心）

#### 5\.3\.1 学历字典管理

由系统超级管理员或HR管理员维护，支持新增、编辑、删除学历层次和专业分类，确保学历信息标准化，避免录入混乱。例如：学历层次可新增“专科”“本科”“硕士”等，专业分类可新增“计算机科学与技术”“汉语言文学”“机械工程”等，支持排序调整，便于前端展示。

#### 5\.3\.2 员工学历录入与编辑

- 新增员工时，可同时录入1条或多条学历记录，选择学历层次（关联字典）、填写专业、毕业院校、毕业时间，上传学历证书图片（可选），提交后关联至员工主表。

- 编辑员工时，可新增学历记录、修改已有学历信息、删除无效学历记录，修改后自动记录日志，确保学历信息的准确性和完整性。

- 学历备案状态管理：HR管理员可审核员工提交的学历信息和学历证书，审核通过后更新备案状态为“已备案”，审核中状态为“审核中”，未提交审核为“未备案”。

#### 5\.3\.3 学历查询与筛选

支持按学历层次、毕业院校、专业等条件筛选员工，可结合部门、在职状态等条件组合筛选，筛选结果可导出Excel，方便HR进行学历统计和分析。

### 5\.4 组织架构管理（钉钉风格）

- 多级部门管理：支持无限级部门嵌套，与钉钉组织架构操作逻辑一致，可新增、编辑、删除部门，调整部门排序。

- 部门员工统计：每个部门页面显示该部门及子部门的员工数量，支持点击查看部门下所有员工信息。

- 拖拽调整：支持拖拽部门调整层级和排序，操作便捷，与钉钉组织架构拖拽功能一致。

### 5\.5 权限管理（同钉钉）

- 超级管理员：拥有系统全部操作权限，可管理所有员工信息、学历信息、履历信息、组织架构、权限配置等。

- HR管理员：拥有员工管理、学历管理、履历查看、组织架构管理权限，可录入、编辑员工信息和学历信息，查看所有员工履历。

- 部门主管：仅可查看本部门及子部门员工的基础信息、学历信息和履历，不可编辑员工信息（除非拥有额外权限）。

- 普通员工：仅可查看自己的个人基础信息、学历信息和个人履历，不可查看其他员工信息，不可进行任何编辑操作。

## 六、前端页面设计（钉钉风格）

### 6\.1 页面整体风格

完全对标钉钉后台管理页面风格，采用简洁、高效的设计，配色、布局、按钮样式与钉钉保持一致，确保用户使用习惯统一，降低学习成本。

## 八、业务流程

### 8\.1 新员工入职流程

1. HR管理员进入员工管理页面，点击“新增员工”，填写钉钉标准必填字段（工号、姓名、手机号、入职时间、部门等）。

2. 填写身份证信息（身份证号），上传身份证正面、反面图片。

3. 填写学历信息，选择最高学历层次，新增学历记录（专业、毕业院校、毕业时间等），上传学历证书（可选）。

4. 提交员工信息，系统校验必填字段合法性，校验通过后保存员工记录。

5. 系统自动生成“入职”类型履历，初始化在职时长数据，完成新员工入职流程。

### 8\.2 部门调动流程

1. HR管理员或部门主管进入员工详情页，点击“部门调动”按钮，选择新部门、新岗位，填写调动原因。

2. 提交调动申请，系统校验新部门、新岗位的合法性，校验通过后更新员工主表的当前部门、当前岗位。

3. 系统自动生成“部门调动”类型履历，记录调动前后的部门、岗位、时间及原因，在职时长继续累加。

4. 调动完成，系统更新员工列表中的部门信息，同步更新相关日志。

### 8\.3 复职流程

1. HR管理员进入员工列表，筛选出离职员工，点击“复职”按钮。

2. 填写复职时间、复职后部门、复职后岗位，填写复职备注（可选）。

3. 提交复职申请，系统校验参数合法性，校验通过后更新员工主表的在职状态（改为在职）、当前入职时间（改为复职时间）。

4. 系统自动生成“复职”类型履历，记录复职时间、部门、岗位，本次在职天数重新开始计算，累计在职天数保留历史数据。

5. 复职完成，系统更新员工列表中的在职状态和部门信息，同步更新相关日志。

### 8\.4 离职流程

1. HR管理员或部门主管进入员工详情页，点击“离职”按钮，填写离职时间、离职原因。

2. 提交离职申请，系统校验参数合法性，校验通过后更新员工主表的在职状态（改为离职）、离职时间。

3. 系统自动计算本次在职天数和累计在职天数，更新至履历表，生成“离职”类型履历。

4. 离职完成，系统更新员工列表中的在职状态，同步更新相关日志，离职员工不可再登录系统。

### 8\.5 学历备案流程

1. HR管理员或员工本人在员工详情页，新增或编辑员工学历信息，上传学历证书图片，提交备案申请。

2. HR管理员进入学历管理页面，查看待审核的学历备案申请，核对学历信息和学历证书的真实性。

3. 审核通过：更新学历备案状态为“已备案”，记录审核日志；审核不通过：退回申请，填写退回原因，通知员工修改后重新提交。

4. 备案完成，学历信息不可随意修改，如需修改需重新提交审核。
