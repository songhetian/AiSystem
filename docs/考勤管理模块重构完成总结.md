## 📝 使用指南

### 快捷键
- **Ctrl+R**: 刷新数据
- **Ctrl+E**: 导出数据
- **Ctrl+S**: 切换排班模式（排班管理页面）
- **Esc**: 退出当前操作

### 操作流程

#### 排班管理
1. 进入排班模式
2. 选择要排班的班次
3. 拖拽或点击表格单元格进行排班
4. 系统自动保存排班数据

#### 考勤记录
1. 设置筛选条件
2. 查看考勤记录列表
3. 选择需要重算的记录
4. 执行批量重算或导出操作

#### 考勤统计
1. 选择统计周期和部门
2. 查看统计概览指标
3. 切换到AI洞察查看分析
4. 导出统计报表
