# 页面重构对比说明

本文档说明页面重构前后的主要变化和优化点。

---

## 一、操作日志页面重构

### 文件位置
- **原版本**: `frontend/src/pages/system/logs/operation/index.tsx`
- **新版本**: `frontend/src/pages/system/logs/operation/index.new.tsx`

### 主要变化

#### 1. 组件替换

| 原组件 | 新组件 | 优势 |
|--------|--------|------|
| `@ant-design/pro-layout` 的 PageContainer | `@/components/layout` 的 PageContainer | 更灵活的配置、毛玻璃效果、面包屑导航 |
| Ant Design Card | `@/components/layout` 的 SectionCard | 可折叠、毛玻璃效果、更好的视觉层次 |
| 自定义 LogFilter | `@/components/business` 的 FilterBar | 统一的筛选体验、响应式布局、展开/收起 |
| 自定义 LogTable | `@/components/ui` 的 Table | 毛玻璃效果、多种密度、斑马纹 |
| 自定义 LogDetailDrawer | `@/components/ui` 的 Drawer | 毛玻璃效果、更好的动画 |
| 自定义 ExportButton | `@/components/business` 的 ActionBar | 统一的操作栏、更好的布局 |

#### 2. 视觉优化

**原版本**:
```tsx
<Card>
  <Space direction="vertical" size="large">
    <LogFilter />
    <div style={{ textAlign: 'right' }}>
      <ExportButton />
    </div>
    <LogTable />
  </Space>
</Card>
```

**新版本**:
```tsx
<SectionCard title="筛选条件" collapsible>
  <FilterBar glass />
</SectionCard>

<SectionCard>
  <ActionBar glass />
  <Table glass density="compact" striped />
</SectionCard>
```

**优化点**:
- ✅ 使用毛玻璃效果，提升视觉层次
- ✅ 区块化布局，内容更清晰
- ✅ 可折叠筛选区域，节省空间
- ✅ 统一的操作栏，更好的对齐
- ✅ 紧凑型表格，显示更多数据
- ✅ 斑马纹表格，提升可读性

#### 3. 功能增强

**面包屑导航**:
```tsx
<PageContainer
  breadcrumb={{
    items: [
      { title: '首页', path: '/' },
      { title: '系统管理' },
      { title: '操作日志' },
    ],
  }}
>
```

**状态标签**:
```tsx
// 原版本：纯文本
{method}

// 新版本：带颜色的标签
<StatusTag
  status={colorMap[method]}
  text={method}
  showDot={false}
/>
```

**筛选器增强**:
```tsx
<FilterBar
  items={[...]}
  collapsible        // 可展开/收起
  defaultRows={2}    // 默认显示2行
  glass              // 毛玻璃效果
/>
```

**操作栏增强**:
```tsx
<ActionBar
  actions={[...]}
  extra={<span>共 {total} 条记录</span>}  // 显示统计信息
  align="space-between"                    // 两端对齐
  glass                                    // 毛玻璃效果
/>
```

#### 4. 详情抽屉优化

**原版本**:
- 使用自定义组件
- 样式不统一
- 缺少视觉层次

**新版本**:
```tsx
<Drawer
  visible={detailVisible}
  title="操作日志详情"
  width={720}
  glass              // 毛玻璃效果
  onClose={handleCloseDetail}
>
  <Space direction="vertical" size="large">
    {/* 基本信息 */}
    <div>
      <h3>基本信息</h3>
      <div style={{ display: 'grid', gridTemplateColumns: '120px 1fr' }}>
        ...
      </div>
    </div>

    {/* 请求数据 */}
    {requestBody && (
      <div>
        <h3>请求数据</h3>
        <pre style={{ background: '#f5f5f5', ... }}>
          {JSON.stringify(requestBody, null, 2)}
        </pre>
      </div>
    )}
  </Space>
</Drawer>
```

**优化点**:
- ✅ 毛玻璃效果
- ✅ 网格布局，对齐更整齐
- ✅ 代码高亮显示
- ✅ 错误信息特殊样式
- ✅ 更好的间距和排版

#### 5. 代码质量提升

**类型定义**:
```tsx
// 新版本添加了完整的类型定义
interface OperationLog {
  id: number;
  userId: number;
  username: string;
  name: string;
  module: string;
  action: string;
  method: string;
  path: string;
  ip: string;
  userAgent: string;
  status: number;
  duration: number;
  errorMessage?: string;
  requestBody?: any;
  responseBody?: any;
  changes?: any;
  createdAt: string;
}
```

**格式化工具**:
```tsx
// 使用统一的格式化工具
import { formatDate } from '@/utils/format';

// 原版本：手动格式化
{new Date(record.createdAt).toLocaleString()}

// 新版本：使用工具函数
{formatDate(record.createdAt)}
```

### 重构原则

1. **保持功能一致**: 不改变原有功能，只优化视觉和体验
2. **渐进式重构**: 一个页面一个页面地重构，不影响其他页面
3. **充分测试**: 每个页面重构后都要充分测试
4. **文档同步**: 及时更新文档和注释

## 五、最佳实践

### 1. 组件使用

```tsx
// ✅ 好的做法：使用统一组件
import { PageContainer, SectionCard } from '@/components/layout';
import { FilterBar, ActionBar } from '@/components/business';
import { Table, Button } from '@/components/ui';

// ❌ 不好的做法：使用自定义组件
import CustomFilter from './components/CustomFilter';
import CustomTable from './components/CustomTable';
```

### 2. 样式定制

```tsx
// ✅ 好的做法：使用props配置
<Table glass density="compact" striped />

// ❌ 不好的做法：直接写样式
<Table style={{ background: 'rgba(255,255,255,0.7)' }} />
```

### 3. 类型定义

```tsx
// ✅ 好的做法：定义完整类型
interface User {
  id: number;
  username: string;
  name: string;
  status: number;
}

// ❌ 不好的做法：使用any
const users: any[] = [];
```

### 4. 格式化工具

```tsx
// ✅ 好的做法：使用工具函数
import { formatDate, formatNumber } from '@/utils/format';
{formatDate(record.createdAt)}

// ❌ 不好的做法：手动格式化
{new Date(record.createdAt).toLocaleString()}
```
